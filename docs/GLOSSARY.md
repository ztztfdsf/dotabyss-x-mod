# 专有名词对照表（Glossary）

本文件是本仓库简体中文译名的**唯一权威来源**。规则：

1. **界面显示名以 `translations/names/zh_Hans.json` 为准** —— AbyssMod 的 `TranslateName()` 是精确查表，
   角色名在名簿/名片/对话人名框上显示的就是表里的那个写法。
2. **剧情正文（novels）、MasterData（static）、UI 文本（ui_texts）必须与上者一致**，
   不允许同一个人在两话里出现两种译名。
3. 新版本翻译时，先在本表查名字；表里没有的新专名，按「音译取常用汉字 + 与既有同类名一致」新增，
   然后**同步写回 `names/zh_Hans.json`**，再用于正文。
4. 地名/组织名（如 `ミレスガルド`）names 表没有精确条目时，由本表 `_说明` 下方的「人工指定」区块定义。

校验工具：`tools/glossary.py`（统计每个日文专名在译文里的实际写法，找出并统一多写法）。
